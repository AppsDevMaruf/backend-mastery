Today's Lesson:

- Browser does not know the IP address.
- DNS converts Domain to IP.
- TCP creates a reliable connection.
- TLS encrypts communication.
- HTTP carries the request.
- Backend processes the request.
- Database returns data.
- Browser renders the response.
