# HTTP Protocol

## HTTP

Protocol for communication between Client and Server.

---

## Request

- URL
- Method
- Headers
- Body

---

## Methods

GET → Read

POST → Create

PUT → Replace

PATCH → Update

DELETE → Delete

---

## Response

- Status Code
- Headers
- Body

---

## Status Codes

200 OK

201 Created

400 Bad Request

401 Unauthorized

403 Forbidden

404 Not Found

500 Internal Server Error
