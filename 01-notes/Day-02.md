# DNS

## Domain

Human readable name

Example

google.com

---

## IP Address

Computer readable address

Example

142.xxx.xxx.xxx

---

## DNS

Maps Domain → IP Address

---

## Why DNS?

Humans remember names.

Computers use IP addresses.

---

## Common DNS Records

- A
- AAAA
- CNAME
- MX
- TXT
